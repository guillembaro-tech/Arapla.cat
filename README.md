# arapla.cat

Web de Guillem Baró. Disseny i construcció de webs WordPress.

Web estàtica publicada amb GitHub Pages des de la branca `main`.

## Fitxers

- `index.html` conté tota la pàgina, amb el CSS i el JS a dins. Les fonts Geist i Geist Mono es carreguen de Google Fonts.
- `favicon.svg`, `favicon.ico` i `apple-touch-icon.png` són les icones, amb el logo Cel·la.
- `og.png` és la imatge que surt quan es comparteix l'enllaç.
- `media/` ha de contenir la captura (`.jpg`) i el clip (`.mp4`) de cada projecte, amb aquests noms: `professordesocials`, `queestudiar`, `cinepetits`, `desdelsofa` i `aprendreambia`.

## Pendent

- Les captures de `media/` són provisionals, en gris i dins d'una finestra mínima. Falten els clips `.mp4`.
- Connectar l'enviament del formulari de contacte. Ara només està maquetat.
- Afegir el domini arapla.cat a la configuració de Pages quan estigui registrat.
